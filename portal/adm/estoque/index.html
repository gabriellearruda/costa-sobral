Importar NF-e

Arraste os arquivos XML das notas de compra. O sistema extrai produto, NCM, unidade, quantidade e valor, classifica a categoria de custo e dá entrada no estoque.

⬇
Arraste os XML das NF-e aqui ou clique para selecionar — aceita vários arquivos de uma vez

Precisa do XML da SEFAZ, não do DANFE em PDF. Todo fornecedor é obrigado a te enviar o XML; se não tiver, dá pra baixar no portal da nota com a chave de acesso.

Lançar por texto / foto sem XML

Não tem o XML? Mande a foto da notinha no chat do Claude — ele devolve os dados neste formato. Cole aqui e o sistema abre a mesma tela de conferência antes de dar entrada.
