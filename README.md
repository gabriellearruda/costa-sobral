# 🛡️ Costa & Sobral — Site Institucional

> **Movendo Confiança, Gerando Valor.**

Site institucional da **Costa & Sobral Soluções e Serviços Ltda.**, empresa especializada em serviços terceirizados para empresas, indústrias, escolas, supermercados e condomínios, sediada em Suzano, SP.

---

## ✨ Sobre o projeto

Site one-page desenvolvido com HTML e CSS puros — sem frameworks, sem dependências, pronto para deploy instantâneo na Vercel.

**Funcionalidades:**
- 📱 Layout responsivo (mobile, tablet, desktop)
- 🌙 Suporte a modo claro e escuro
- 💬 Botão flutuante de WhatsApp
- 🗺️ Informações de contato, endereço e horários
- 🎨 Identidade visual fiel à marca (preto, ouro, prata)

---

## 🚀 Deploy

Hospedado na [Vercel](https://vercel.com). Qualquer push na branch `main` atualiza o site automaticamente.
